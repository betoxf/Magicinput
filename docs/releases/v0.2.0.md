Use one keyboard and mouse across your Mac and Windows PC. **MagicInput 0.2.0** lets your keyboard follow your last click.

### What's new

- **The keyboard follows the click.** Type on the Mac, click into a text field with the PC's own mouse, and keep typing on the Mac keyboard: it types on the PC. Click on the Mac again and it types on the Mac. It works the same the other way round.
- The keyboard comes back when you click on its own computer, move that computer's mouse deliberately, or press **Control+Option+Esc** (**Ctrl+Alt+Esc** on the PC). Held keys are released whenever it switches, so nothing gets stuck.
- While your keyboard is typing on the other computer, the panel says so ("Keyboard typing on …").
- Prefer the old behavior? Set `keyboard_follows_click = false` in the config file (`magicinput config` shows where it is).

### Fixed

- Reinstalling on a Mac while MagicInput is running no longer fails with "Bootstrap failed: 5".
- `magicinput status` reports a stopped service as not running right away.

> [!IMPORTANT]
> **Update both computers.** 0.2.0 uses a new protocol version, so a computer on 0.2.0 won't connect to one still on 0.1.x.

### Install or update

**macOS 13+ — Apple silicon and Intel, signed and notarized:**

```bash
brew install --cask betoxf/tap/magicinput
# Already installed:
brew update
brew upgrade --cask magicinput
```

Or download `MagicInput-macOS.zip`, unzip, and move MagicInput to Applications.

**Windows 10/11 (64-bit):** download `MagicInput-Windows.zip`, unzip, open `magicinput-app.exe`, and accept the administrator prompt. The Windows build is not code-signed; SmartScreen may require **More info → Run anyway**.

**Updating on Windows:** in the unzipped folder, open PowerShell (Shift + right-click → *Open PowerShell window here*) and run the line below, then accept the administrator prompt. It replaces the installed copy and restarts MagicInput.

```powershell
Start-Process .\magicinput.exe -ArgumentList install -Verb RunAs
```

New here? Open MagicInput on both computers, allow Accessibility and Input Monitoring on the Mac, and pair through the link icon. Both computers must be on the same local network. Or paste the prompt from the README into an AI assistant on each computer and let it set things up ([runbook](https://github.com/betoxf/Magicinput/blob/main/docs/AI_SETUP.md)).

Verify downloads with `SHA256SUMS.txt`. See the [setup guide](https://github.com/betoxf/Magicinput#quick-start).
