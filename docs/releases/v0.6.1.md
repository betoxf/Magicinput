Use one keyboard and mouse across your Mac and Windows PC. **MagicInput 0.6.1 has a new icon.**

### What changed

- **New icon:** two overlapping squares. It's simpler and clearer at small sizes, and you'll see it in the Dock, the menu bar, the Windows tray, the installers and the panel. The Mac menu bar draws it live, so it stays sharp on any screen.
- Everything from 0.6.0 is still here, including **AirDrop to your Windows PC**: AirDrop to the Mac while you're working on the PC, and the file lands in the PC's Downloads folder.

0.6.1 connects to computers on 0.6.0, 0.5.0 and 0.4.0. Update both computers to use AirDrop to the PC.

### Install

- **Mac (macOS 13+):** open `MagicInput.dmg` and drag MagicInput to Applications, or `brew install --cask betoxf/tap/magicinput` (`brew upgrade --cask magicinput` to update).
- **Windows 10/11:** run `MagicInput-Setup.exe` and click Install. Running a newer setup updates MagicInput and keeps your settings. The setup isn't code-signed yet, so SmartScreen may ask you to choose **More info → Run anyway**.

Free for personal use, with every feature. Businesses need a license, from [bullfighterstudio.com/magicinput](https://bullfighterstudio.com/magicinput#business). `SHA256SUMS.txt` lists the checksums of every download.
