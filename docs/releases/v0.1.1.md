Use one keyboard and mouse across your Mac and Windows PC. **MagicInput 0.1.1** fixes control handoff when you switch back to the other computer’s own input devices.

### What changed

- **Reclaim control naturally.** While the Mac is driving the PC, using the PC’s own mouse or keyboard brings control back to the PC. You can then push across the screen edge to drive the Mac. The same works in reverse.
- A deliberate mouse movement (more than 24 points within half a second), click, or key press reclaims control. Small accidental mouse movements do not.
- **Clean release builds.** Local build-machine usernames and source paths are remapped out of the Mac and Windows binaries.

### New

- **`magicinput status`** shows whether MagicInput is installed and running, the pairing code, the connection, and other computers nearby, with the next step to take. `--json` makes it easy for scripts and AI assistants.
- **Set up with an AI assistant:** paste the prompt from the README into Claude, ChatGPT, Codex or Cursor on each computer and it installs and pairs MagicInput for you ([runbook](https://github.com/betoxf/Magicinput/blob/main/docs/AI_SETUP.md)).

### Included features

Bidirectional keyboard, mouse and scroll sharing; text clipboard sharing; automatic Command/Control swapping; automatic local-network discovery; pairing codes and encrypted connections; draggable display arrangement, including an iPad connected to the Mac through Sidecar; start at login.

### Install or update

**macOS 13+ — Apple silicon and Intel, signed and notarized:**

```bash
brew install --cask betoxf/tap/magicinput
# Already installed:
brew update
brew upgrade --cask magicinput
```

Or download `MagicInput-macOS.zip`, unzip, and move MagicInput to Applications.

**Windows 10/11 (64-bit):** download `MagicInput-Windows.zip`, unzip, open `magicinput-app.exe`, and accept the administrator prompt. Quit the previous version before replacing it. The Windows build is not code-signed; SmartScreen may require **More info → Run anyway**.

Open MagicInput on both computers, allow Accessibility and Input Monitoring on the Mac, and pair through the link icon. Both computers must be on the same local network. iPad support uses the Mac’s Sidecar display; there is no standalone iPad app.

Verify downloads with `SHA256SUMS.txt`. See the [setup guide](https://github.com/betoxf/Magicinput#quick-start).

**Display arrangement tip:** crossings only work where the screens touch in the saved layout. Align their top edges in Displays if a top strip does not lead to the other computer.
