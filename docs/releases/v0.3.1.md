Use one keyboard and mouse across your Mac and Windows PC. **MagicInput 0.3.1** brings real installers for Mac and Windows, and Homebrew is back.

### New

- **Mac disk image.** Open `MagicInput.dmg` and drag MagicInput to Applications. Signed and notarized by Apple.
- **Windows setup.** Run `MagicInput-Setup.exe` and click Install: it installs MagicInput, starts it now and at every sign-in, allows it through the firewall on private networks, opens it when done, and adds MagicInput to the Start menu and to Settings → Apps (with an uninstaller). Running a newer setup updates it and keeps your settings. `/S` installs silently.
- **Homebrew is free again:** `brew install --cask betoxf/tap/magicinput`.

### Fixed

- Windows: opening `magicinput-app.exe` from a newer download now updates the installed copy instead of opening the old one.

### Get it

- **Mac, free:** `brew install --cask betoxf/tap/magicinput` (or `brew upgrade --cask magicinput`).
- **Ready-made installers:** your download page at [bullfighterstudio.com/magicinput](https://bullfighterstudio.com/magicinput): $10 per device per month, $96 per device per year, or $199 once for a Mac and a PC.
- **Any computer, free:** [build it from source](https://github.com/betoxf/Magicinput#build-from-source) (GPL-3.0).

`SHA256SUMS.txt` lists the checksums of the disk image, the setup and the Homebrew zip. The Windows setup isn't code-signed yet, so SmartScreen may ask you to choose **More info → Run anyway**.
