### What changed

- **Open source (GPL-3.0).** Read the code, have it audited, or [build it yourself](https://github.com/betoxf/Magicinput#build-from-source) for free.
- **Official installers.** The signed and notarized Mac app and the Windows app, with updates, are at [bullfighterstudio.com/magicinput](https://bullfighterstudio.com/magicinput): $10 per device per month, $96 per device per year, or $199 once for a Mac and a PC ([pricing](https://github.com/betoxf/Magicinput/blob/main/PRICING.md)).
- **Verify your download.** `SHA256SUMS.txt` below lists the checksums of this version's official installers: `shasum -a 256 MagicInput-macOS.zip`.
- The app itself works exactly like 0.2.0, and a 0.3.0 computer connects to one still on 0.2.0.

### Install or update

Get the installers from your download page at [bullfighterstudio.com/magicinput](https://bullfighterstudio.com/magicinput) (the page you reach after paying; bookmark it).

- **macOS 13+:** unzip and move MagicInput to Applications. Installed with Homebrew before? Run `brew uninstall --cask magicinput` first; your settings stay.
- **Windows 10/11:** unzip and open `magicinput-app.exe`. Already installed? In the unzipped folder, run `Start-Process .\magicinput.exe -ArgumentList install -Verb RunAs` in PowerShell.

New here? Open MagicInput on both computers, allow Accessibility and Input Monitoring on the Mac, and pair them through the link icon.
