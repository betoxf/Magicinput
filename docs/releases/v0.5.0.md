Use one keyboard and mouse across your Mac and Windows PC. **MagicInput 0.5.0 is free for personal use, with every feature.**

### What changed

- **Free, with every feature.** No trial, no account, nothing to unlock. Use it on as many of your own computers as you like.
- **Real installers, right here.** Download the signed and notarized Mac disk image or the Windows setup below. Homebrew works too: `brew install --cask betoxf/tap/magicinput`.
- **Business use needs a license:** $10 a month, $96 a year or $199 once, for all your company's computers, at [bullfighterstudio.com/magicinput](https://bullfighterstudio.com/magicinput#business). Paste the key into MagicInput (click **Free for personal use** at the bottom of the panel) and it shows **Business license**. Nothing is locked without it.
- **New license:** the [PolyForm Noncommercial License 1.0.0](https://github.com/betoxf/Magicinput/blob/main/LICENSE). The source code stays public. Versions 0.3.0 to 0.4.0 stay under the GPL-3.0.
- Connects to computers still on 0.4.0.

### Install

- **Mac (macOS 13+):** open `MagicInput.dmg` and drag MagicInput to Applications, or `brew install --cask betoxf/tap/magicinput` (`brew upgrade --cask magicinput` to update).
- **Windows 10/11:** run `MagicInput-Setup.exe` and click Install. Running a newer setup updates MagicInput and keeps your settings. The setup isn't code-signed yet, so SmartScreen may ask you to choose **More info → Run anyway**.

Open MagicInput on both computers, allow Accessibility and Input Monitoring on the Mac, and pair them through the link icon. `SHA256SUMS.txt` lists the checksums of every download.
